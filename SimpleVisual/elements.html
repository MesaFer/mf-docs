Elements

scenes.<X>.elements — an array. Types: window text button picture gauge shape command list particles (MF.SimpleVisual.ELEMENT_TYPES).

{ "id": "logo",  "type": "picture", "image": "pictures/Logo", "anchor": "top", "y": 8, "z": -1 }
{ "id": "steps", "type": "text",    "text": "Steps: \\V[1]", "x": 20, "y": 560 }
{ "id": "quit",  "type": "button",  "text": "To map", "action": { "type": "back" } }

particles

{ "id": "snow", "type": "particles", "preset": "snow", "width": "100%", "height": "100%", "z": -1, "count": 150, "wind": 0.5, "mouseRepel": 80 }

Presets: rain snow embers fireflies stars. Overridable: count shape (dot streak) image color sizeMin sizeMax speedMin speedMax angle spread opacityMin opacityMax spawn (top bottom area) lifeMin lifeMax sway wind gravity spin flicker pulse fade alignToMotion blend (normal add) mouseRepel. Numbers accept expressions. Frozen in the editor.

Row templates

Child types: text icon face picture shape gauge actorGauge actorState. x y width height anchor are relative to the row content area (default anchor left), accept row fields: "{hpRate}%". {selected} and {enabled} are available.

States and sounds

{ "id": "buy", "type": "button", "text": "Buy", "enabled": { "gold": 100, "op": ">=" },
  "fill": "#2a3040", "hover": { "fill": "#3a5a8a" }, "pressed": { "fill": "#203048" },
  "disabled": { "textColor": "#808080", "opacity": 150 },
  "hoverSound": "Cursor2", "disabledSound": "Buzzer2" }
  • hover, pressed (over hover), disabled — overrides of own properties.
  • enabled — condition; disabled elements play disabledSound.
  • blink (seconds per cycle), blinkMin (0–255, default 96), blinkTarget: background content all.
  • Sounds: "Cursor1" or { name, volume, pitch, pan }; "none" — silent; unset — MZ sound.

Nested elements

{ "id": "badge", "type": "picture", "image": "pictures/Badge", "parent": "w:_statusWindow", "anchor": "top-right" }

parent: "w:<window field>" or an element id. Geometry is relative to the parent's inner area; the child follows it and hides with it.
