File format — data/SimpleVisual.json

Format version 1. A file without "version" is treated as v0 and migrated. Missing properties keep the standard value.

Root

{
  "version": 1,
  "baseResolution": { "width": 816, "height": 624 },
  "theme": "default",
  "themes": { },
  "scenes": { },
  "menuCommands": [ ],
  "presets": { }
}
FieldTypeDescription
versionnumberFormat version (MF.SimpleVisual.FORMAT_VERSION)
baseResolutionobjectResolution the layout was made for
scaleMode, scaleFontsstring, booleanSee Resolution
themestringTheme for all scenes
themesobjectNamed themes
scenesobjectKey — scene class name or custom scene id
menuCommandsarrayMain menu items
presetsobjectPartial layouts over the file
windowTemplatesobjectEditor only: saved groups of elements

Keys starting with _, comment and extends are never reported as unknown.

Sizes and positions

ValueMeaning
240Pixels
"50%"Percent of the container (UI area Graphics.boxWidth/boxHeight, parent, or template row)
"100%-240", "(100%-20)/2"Expression
"auto"Height from rows or the number of items

anchor: top-left (default), top, top-right, left, center, right, bottom-left, bottom, bottom-right. x / y are offsets from the anchor point.

Expressions

Numeric properties (x, y, width, height, rotation, opacity, picture settings, particle numbers) accept expressions of MF.Units (MF_Core 1.1.0). No eval.

  • Operators: + - * / ^ ( ), % of the container, < > <= >= == != (1 / 0), && || !, cond ? a : b.
  • Functions: min max abs sign floor ceil round trunc sqrt pow exp log mod clamp lerp step between if hypot dist sin cos tan asin acos atan atan2 sind cosd tand atan2d angle deg rad; constants pi, e.
  • Fallback after |: {actor.9.hp|100}, \V[5|0] — used when the value is missing, empty or not a number. Without it: 0 (in text — empty).
  • An error (syntax, division by zero) keeps the standard value, with a console warning; the editor shows it under the field.
  • Recalculated every 10 frames when inputs change; with {mouse.}, {self.}, {el.}, map tokens — every frame.
{ "id": "hpBar", "type": "shape", "x": 8, "y": 8, "height": 12, "width": "{leader.hpRate}*2", "fill": "#d04040", "radius": 6 }

Map tokens

TokenFields

Mouse, self, el

  • {mouse.*}: x y uiX uiY left right middle pressed dragging dragX dragY dragStartX dragStartY clickX clickY clicks rightClicks wheel idle, over.<id> down.<id> relX.<id> relY.<id>.
  • {self.*} — the element / window itself, {el.<id>.*} — another element: x y width height centerX centerY right bottom rotation opacity visible hover down relX relY clicks hoverTime time parentWidth parentHeight. Geometry from the previous layout pass.
Mouse / self tokens work in numeric properties, not in conditions. hover / relX ignore element rotation.

Themes

"themes": {
  "default": { "windowskin": "Window", "fontFace": "rmmz-mainfont", "fontSize": 26, "backOpacity": 192, "padding": 12 },
  "dark":    { "extends": "default", "label": "Dark", "backOpacity": 230 }
}

Style properties: windowskin fontFace fontSize opacity backOpacity contentsOpacity padding + text style, extends, label (name shown to the player). Applied to all windows of a scene; window properties override it.

Scenes and inheritance

"Scene_Menu": {
  "theme": "dark",
  "windows":  { "_goldWindow": { "visible": false } },
  "sprites":  { },
  "elements": [ ]
}

The key is the class name; layouts of parent classes are inherited and more specific classes override them: Scene_MenuBase → all menus, Scene_File → Scene_Save / Scene_Load, Scene_Message → Scene_Map / Scene_Battle. Elements with the same id in a child class override inherited ones.

FieldDescription
themeTheme of the scene
windows, sprites, elementsSee below and Elements
skip / forceLeave standard / apply despite autoCompat
custom, background, initialFocusCustom scenes

Text style and fonts

Windows, text elements and themes: textColor (palette index 0–31 or "#rrggbb"), outlineColor, outlineWidth, fontBold, fontItalic.

fontFace: a family (rmmz-mainfont) or a file in fonts/ ("PixelFont.ttf"; ttf, otf, woff, woff2) — loaded at startup.

Rows and commands of standard windows

"_statusWindow": {
  "rowHeight": 120,
  "template": [
    { "type": "face", "anchor": "top-left", "width": 100, "height": "100%-2" },
    { "type": "text", "text": "{name}  Lv {level}", "anchor": "top-left", "x": 110 },
    { "type": "actorGauge", "stat": "hp", "anchor": "top-left", "x": 110, "y": 40 }
  ]
},
"_commandWindow": {
  "commands": { "item": { "icon": 176 }, "formation": { "visible": false }, "gameEnd": { "order": 0, "text": "Quit" } }
}

template replaces the standard drawing (see row templates). Row data: Window_MenuStatus / Window_BattleStatus — actor fields; Window_ItemList — item + count; Window_SkillList — skill + mpCost tpCost; Window_Command — name symbol index status iconIndex.

commands (Window_Command only): key — symbol or #<index>; text visible order icon align color background.

Sprites

scenes.<X>.sprites.<field>: _backSprite1 _backSprite2 _gameTitleSprite (title), _backgroundSprite (menus), _cancelButton (battle), _menuButton (map).

Properties: x y (percent of Graphics.width/height), scaleX scaleY opacity visible image; title: titleText titleFontFace titleFontSize titleColor titleOutlineColor titleOutlineWidth.

Resolution

"scaleMode": "scale" at the root scales plain pixel x y width height written for baseResolution to the current UI area; "scaleFonts": true scales fontSize. Percentages, auto and expressions are unchanged. Scaling is off in the editor.

Compatibility

  • scenes.<X>.skip: true or parameter skipScenes — scene and its child classes stay standard.
  • autoCompat: scenes rebuilt by known plugins are skipped unless force: true.
