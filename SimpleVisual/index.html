MF_SimpleVisual — Reference

Declarative UI layout for RPG Maker MZ: re-arrange windows of built-in scenes, add pictures, text, gauges, buttons, lists and particles, build custom scenes, map HUD and battle layouts — all from data/SimpleVisual.json, with a visual editor (MF_SimpleVisualEditor, F10 in test play).

Overview

PluginVersionRole
MF_Core1.1.0+Required base library (units, expressions, conditions, data files, saves)
MF_SimpleVisual0.8.0Runtime: reads the file and applies it. Needed in the released game
MF_SimpleVisualEditor0.7.0Visual editor, test play only. Does nothing in a deployed game

The layout file is optional: without it (or with enabled off) the game keeps the standard look. A broken file is reported in the console and ignored.

Installation

  1. Copy MF_Core.js, MF_SimpleVisual.js and (for development) MF_SimpleVisualEditor.js to js/plugins/.
  2. Order in the Plugin Manager: MF_Core → MF_SimpleVisual → MF_SimpleVisualEditor. Place SimpleVisual below plugins that change windows.
  3. Start test play, open any scene, press F10. Saving creates data/SimpleVisual.json (backup SimpleVisual.bak.json).

Pitfalls

  • Order: MF_Core first, SimpleVisual below window pluginsLayouts are applied after create() / start(). A plugin that moves windows every frame overwrites them — skip that scene.
    See: Compatibility
  • Unknown or invalid properties are ignoredWith one console warning each. Check the console (F8) when a property "does nothing".
    See: Error handling
  • Backslashes are doubled in JSON"\\V[1]", "\\C[2]". The editor does this for you.
  • script actions need MF_Core Allow ScriptsOtherwise they do nothing. Prefer call and pluginCommand.
    See: Actions
  • Message windows reposition themselves_messageWindow recalculates y for every message (top / middle / bottom).
  • command and list are interactive only in custom scenesElsewhere they only display.
  • Deprecated names still work — for nowA one-time console warning names the replacement and the removal version. Save the file in the editor to upgrade it.
    See: Versioning policy
